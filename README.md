# كيبوردي

تطبيق ويب مجاني لتعلّم الطباعة باللمس بالعربية والإنجليزية على لوحة مفاتيح الماك، بواجهة عربية كاملة.

## المزايا

- منهج عربي ومنهج إنجليزي، يبدأ بالصف الأوسط ثم العلوي ثم السفلي، ثم Shift والأرقام والجمل والفقرات.
- مبني على تخطيط **Arabic** الأصلي في macOS، مع خيار **Arabic – PC**، ودعم لوحات ISO و ANSI.
- لوحة مفاتيح ملوّنة حسب الأصابع، ورسم لليدين يوضّح الإصبع المطلوب في كل ضغطة.
- نجوم لكل درس، واختبار سرعة، وإحصائيات، وتدريب تلقائي على المفاتيح التي تخطئ فيها.
- لا يحتاج إلى حساب أو خادم. التقدم محفوظ في متصفحك فقط.
- يمكن تثبيته على الماك من Safari عبر File ثم Add to Dock، ويعمل بعدها دون إنترنت.

## التشغيل

افتح `index.html` مباشرة في المتصفح.

## النشر على GitHub Pages

1. ارفع محتوى هذا المجلد إلى مستودع على GitHub.
2. من Settings ثم Pages اختر Deploy from a branch، ثم الفرع `main` والمجلد `/ (root)`.
3. سيصبح الموقع متاحًا على `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`.

## بنية المشروع

| الملف | الوظيفة |
| --- | --- |
| `js/layouts.js` | خرائط المفاتيح المستخرجة من macOS |
| `js/words.js` | بنك الكلمات والجمل والفقرات |
| `js/curriculum.js` | ترتيب الدروس وتوليد التمارين |
| `js/engine.js` | لوحة المفاتيح واليدان ومحرك الكتابة |
| `js/storage.js` | حفظ التقدم والإعدادات |
| `js/app.js` | الصفحات والتنقل |
